# شعار ITCITADEL

حرف C من الاسم صار قوس بوابة، وحرف I ضوء برتقالي يقف في مدخلها: الدخول إلى خدماتك الرقمية.

| الملف | الاستعمال |
|---|---|
| `itcitadel-logo-white.png` | الشعار مع الاسم، على الخلفيات الداكنة (الموقع، فيسبوك، إنستغرام) |
| `itcitadel-logo-black.png` | الشعار مع الاسم، على الخلفيات الفاتحة (الأوراق، الوصلات) |
| `itcitadel-mark-white.svg` / `itcitadel-mark-black.svg` | الرمز وحده بصيغة متجهة، لأي حجم (اللافتة، الطباعة) |
| `itcitadel-icon-1024.png` | صورة الحساب على مواقع التواصل، وأيقونة التطبيق |

## القواعد
- **الألوان:** الأسود `#000000` أو `#0B0B0C`، والأبيض `#F5F5F7`، والبرتقالي `#FF6A00`. البرتقالي للضوء وحده.
- **الخط:** Bricolage Grotesque (رخصة SIL OFL المجانية). «IT» متوسط، و«CITADEL» عريض جداً، وتباعد الحروف خفيف.
- **في رأس الموقع:** كل 10 ثوانٍ تنفتح البوابة، فيخرج الضوء ليصبح حرف I، وتستدير البوابة لتصبح حرف C، وتكتمل كلمة ITCITADEL، ثم تعود.
- **المساحة الفارغة:** حول الشعار مساحة فارغة لا تقل عن عرض الضوء البرتقالي.
- **أصغر حجم:** 16 بكسل للرمز وحده، و24 بكسل للشعار مع الاسم.
- **لا يُغيَّر:** لا تمدّد الشعار، ولا تغيّر ألوانه، ولا تضع الضوء البرتقالي على خلفية برتقالية.

كل هذه الصور تُولَّد من رسم واحد في `src/components/logo-mark.ts`، بالأمر `npm run brand`.
